# 📓 Notebooks d'exploration

Ce répertoire contient les notebooks Jupyter pour :

- **EDA** : Exploration des données véhicules (distributions, corrélations)
- **ML Experiments** : Prototypage des modèles (XGBoost, Isolation Forest)
- **A/B Testing** : Analyse des tests de recommandation
- **NLP Analysis** : Tests d'embeddings et de similarité sémantique

## Structure

```
notebooks/
├── 01_eda_vehicles.ipynb            # Exploration données véhicules
├── 02_price_prediction.ipynb        # Prototypage XGBoost
├── 03_recommendation_eval.ipynb     # Évaluation moteur hybride
├── 04_anomaly_detection.ipynb       # Calibration Isolation Forest
└── 05_embedding_analysis.ipynb      # Visualisation embeddings (t-SNE)
```
